# FEM Solver — Метод скінченних елементів на Python

Реалізація двовимірного МСЕ (метод скінченних елементів) на Python із підтримкою **Q8-елементів**, **mortar-методу** для неспівпадаючих сіток.

## Структура проекту

```
├── shape_functions.py       # Функції форми Q8 та їхні похідні (shape_functions_q8)
├── element_stiffness.py     # Локальна матриця жорсткості елемента
├── boundary_conditions.py   # Накладання граничних умов Діріхле / Неймана
├── assemble.py              # Збірка глобальної матриці (assemble_q8)
├── solve.py                 # Розв'язання системи (solve_fem)
├── mesh_generator.py        # Генерація прямокутних сіток (create_beam_mesh)
├── mortar.py                # Mortar-інтерфейс (MortarInterface, couple_meshes)
├── fem_example.py           # Консольна балка: Q8 МСЕ vs аналітичний розв'язок
└── mortar_example.py        # Консольна балка: mortar-з'єднання двох сіток
```

## Задача: консольна балка

Усі приклади верифікуються на консольній балці зі знайомим аналітичним розв'язком балки Ейлера–Бернуллі:

| Параметр | Значення |
|---|---|
| Матеріал (сталь) | E = 210 ГПа, ν = 0.3 |
| Геометрія | L = 1.0 м, H = 0.2 м |
| Навантаження | P = 1000 Н (розподілене по правому торцю) |
| Елемент | Q8 |

Аналітичні поля для порівняння:

```
u_x(x,y)     =  P·y·(2L−x)·x / (2EI)
u_y(x)       = −P·(3Lx² − x³) / (6EI)
σ_xx(x,y)    = −P·(L−x)·y / I
```

### Mortar-з'єднання неспівпадаючих сіток

```bash
python mortar_example.py
```

Ділить балку на дві підобласті в `x = 0.5`:
- ліва: груба сітка (nx=8, ny=3)
- права: дрібна сітка (nx=12, ny=5)

Вузли на інтерфейсі **не збігаються**. Mortar-метод забезпечує неперервність переміщень слабким способом через множники Лагранжа. Виводить також якість інтерфейсу:

```
Interface gap (L2): x.xxxe-xx  (should be small)
Max displacement jump: x.xxxe-xx m
```

## Архітектура розв'язувача


Напруження `σ_xx` обчислюються через **екстраполяцію з точок Гауса** (`bilinear_extrap`) до вузлів із подальшим осередненням по спільних вузлах елементів.

---

## Mortar-метод

`MortarInterface` будує матрицю зв'язку між slave- та master-вузлами на інтерфейсі через числове інтегрування (n_gauss точок). `couple_meshes` збирає розширену систему з множниками Лагранжа:

```
⎡ K1   0   Bₛᵀ ⎤ ⎧ U1 ⎫   ⎧ F1 ⎫
⎢  0  K2  −Bₘᵀ ⎥ ⎨ U2 ⎬ = ⎨ F2 ⎬
⎣ Bₛ −Bₘ   0   ⎦ ⎩ λ  ⎭   ⎩ 0  ⎭
```

Це дозволяє з'єднувати сітки з **різною густиною** без вимоги збігу вузлів на спільній межі.
