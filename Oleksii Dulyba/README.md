# Стиснення зображень методом адаптивної тріангуляції Делоне

Програма реалізує алгоритм стиснення цифрових зображень на основі адаптивної тріангуляції Делоне з автоматичним контролем якості за метриками PSNR та MSE.

## Про що задача

Замість того щоб зберігати кожен піксель окремо (як у BMP чи PNG), програма апроксимує зображення набором трикутників. Кожен трикутник заповнюється середнім кольором пікселів всередині нього. Алгоритм автоматично визначає де потрібно більше трикутників (межі об'єктів, дрібні деталі), а де достатньо кількох великих (однорідні зони).

Процес ітераційний:
1. Будується початкова груба сітка з 8 точок
2. Рахується похибка апроксимації для кожного трикутника
3. Найгірші трикутники розбиваються на дрібніші
4. Повторюється до досягнення заданої якості (PSNR або MSE)

## Структура проєкту

```
├── main.py                  # Точка входу, конфігурація параметрів
├── triangulation_logic.py   # Ядро алгоритму (тріангуляція, рендеринг, метрики)
├── visualization_utils.py   # Візуалізація результатів
└── result_duplom/           # Папка з результатами (створюється автоматично)
```

```bash
pip install numpy Pillow triangle opencv-python scikit-image matplotlib
```

## Як користуватись

Всі параметри задаються у верхній частині файлу `main.py`:

```python
IMAGE_PATH          = "/шлях/до/вашого/фото.bmp"  # шлях до зображення
MAX_AREA            = 300.0   # максимальна площа трикутника (пікселів²)
PSNR_THRESHOLD      = 38.0    # поріг якості в дБ (або None)
MSE_THRESHOLD       = None    # поріг MSE (або число, наприклад 10.0)
MAX_ITERATIONS      = 10      # максимальна кількість ітерацій
WORST_TRI_PER_ITER  = 150     # кількість найгірших трикутників на ітерацію
POINTS_PER_TRI      = 20      # нових точок на кожен трикутник
SAVE_DIR            = None    # папка для збереження графіків (None = не зберігати)
SHOW                = True    # показувати графіки під час роботи
RESULT_DIR          = "result_duplom"  # папка для стисненого зображення
```

Після налаштування запустіть:

```bash
python main.py
```

## Параметри та їх вплив

| Параметр | Менше значення | Більше значення |
|---|---|---|
| `MAX_AREA` | Густіша початкова сітка, повільніше | Грубіша початкова сітка, швидше |
| `PSNR_THRESHOLD` | Менша якість, менше ітерацій | Вища якість, більше ітерацій |
| `WORST_TRI_PER_ITER` | Повільніша збіжність | Швидша збіжність, але більше точок |
| `POINTS_PER_TRI` | Менше нових точок за ітерацію | Більше нових точок за ітерацію |
