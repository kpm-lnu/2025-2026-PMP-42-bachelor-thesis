## Опис проєкту

Проєкт реалізує сервіс планування маршрутів безпілотних транспортних засобів у двовимірному середовищі зі статичними перешкодами на основі тріангуляції Делоне.

Робота охоплює адаптивну генерацію точок, побудову обмеженої тріангуляції Делоне, формування графа центроїдів, пошук оптимального маршруту алгоритмом A*, а також кінематичне згладжування результату за підходом «Пряма-Дуга-Пряма» з використанням жорстких B-сплайнів.

Головна мета проєкту — розробити сервіс, що гарантує геометрично безпечний маршрут: жодна точка траєкторії не може наближатися до перешкоди ближче ніж на заданий користувачем відступ δ, а сам маршрут є кінематично досяжним для реального автономного апарату.

## Основні завдання

Проєкт охоплює такі етапи:

- огляд та аналіз алгоритмів тріангуляції Делоне;
- побудова еквідистантних буферних зон безпеки навколо перешкод;
- адаптивна генерація точок із концентрацією біля меж перешкод;
- побудова обмеженої тріангуляції Делоне та фільтрація небезпечних трикутників;
- формування графа центроїдів і пошук оптимального маршруту алгоритмом A*;
- кінематичне згладжування маршруту методом «Пряма-Дуга-Пряма» з жорсткими B-сплайнами;
- розробка інтерактивного графічного інтерфейсу із функціоналом збереження та завантаження карти.

## Встановлення

Встановіть необхідні бібліотеки Python:

```bash
pip install numpy matplotlib scipy networkx shapely
```

Вимагається Python версії 3.10 або новішої. Рекомендується використовувати Visual Studio Code або інше зручне середовище розробки.

## Запуск програми

```bash
python main.py
```

Після запуску відкриється інтерактивне вікно графічного інтерфейсу. Параметри задаються покроково:

1. Задати розмір карти `L`;
2. Додати вершини перешкод кліком на карті (ліва кнопка миші — додати точку, права кнопка або кнопка «Замкнути» — завершити полігон);
3. Встановити стартову та кінцеву точки маршруту;
4. Задати параметри алгоритму: кількість точок `N` та відступ безпеки `δ`;
5. Натиснути «Запустити» для обчислення та візуалізації маршруту.

Для завантаження готової карти скористайтеся кнопкою «Відкрити» та оберіть JSON-файл конфігурації.

## Параметри алгоритму

| Параметр | Опис |
|----------|------|
| `N` | Кількість точок семплування для тріангуляції |
| `δ` | Відступ буферної зони безпеки навколо перешкод (одиниці карти) |

## Ключові компоненти алгоритму

- **Буферна зона безпеки** — еквідистантне геометричне розширення контурів усіх перешкод на δ за допомогою `shapely.buffer()`;
- **Адаптивна генерація точок** — 70% точок концентрується в адаптивній зоні навколо буфера, 30% розподіляється рівномірно;
- **Тріангуляція Делоне** — будується за допомогою `scipy.spatial.Delaunay`; трикутники, що перетинають буфер, відкидаються;
- **Граф центроїдів** — граф NetworkX, де вузли — центроїди трикутників, а ваги ребер — евклідові відстані між ними;
- **Пошук A*** — знаходить найкоротший шлях з евклідовою евристикою;
- **Згладжування «Пряма-Дуга-Пряма»** — локальне кінематичне згладжування в кутах за допомогою жорстких кубічних B-сплайнів (`scipy.interpolate.splprep/splev`).

## Залежності

| Бібліотека | Призначення |
|------------|-------------|
| `numpy` | Операції з масивами та обчислення відстаней |
| `scipy` | Тріангуляція Делоне та B-сплайнове згладжування |

| `matplotlib` | Візуалізація результатів та інтерактивний інтерфейс |

## Примітки

Алгоритм наразі підтримує лише статичні перешкоди. Якість маршруту покращується зі збільшенням `N`, однак час обчислень зростає відповідно. У вузьких проходах між перешкодами рекомендується використовувати більшу кількість точок для забезпечення зв'язності графа.

Репозиторій містить повний вихідний код, JSON-конфігурації карт та всі матеріали, необхідні для відтворення експериментів, описаних у бакалаврській роботі.
