# Код до бакалаврської роботи

У даній директорії розміщено програмний код та допоміжні матеріали до бакалаврської кваліфікаційної роботи.

## Автор

Пасічна Вікторія, студентка групи ПМП-42.

## Постановка задачі

Метою роботи є розроблення програмної системи для формування синтетичних наборів даних геометричних фігур, а також дослідження впливу різних методів попередньої обробки зображень і аналізу кривизни контурів на якість детекції об'єктів моделлю YOLOv8.

У межах роботи реалізовано систему формування наборів даних, застосування різних методів попередньої обробки зображень, навчання моделі YOLOv8, оцінювання результатів та аналізу контурів на основі кривизни.

## Реалізовані методи попередньої обробки

* Перетворення у відтінки сірого (Grayscale);
* Фільтр середнього (Mean Filter);
* Гаусове згладжування (Gaussian Blur);
* Медіанна фільтрація (Median Filter);
* Оператор Собеля (Sobel Operator);
* Оператор Робертса (Roberts Operator);
* Оператор Лапласа (Laplacian Operator);
* Difference of Gaussians (DoG);
* Laplacian of Gaussian (LoG);
* Детектор країв Кенні (Canny Edge Detector);
* Комбінований метод Gaussian + Canny;
* Аналіз кривизни контурів (Curvature-Based Processing).

## Методи оцінювання

Для оцінювання якості детекції використовуються такі метрики:

* Precision;
* Recall;
* mAP50;
* mAP50-95;
* F1-Score.

## Використані технології

* Python 3;
* OpenCV;
* NumPy;
* Pandas;
* Matplotlib;
* Ultralytics YOLOv8;
* SQLite.

## Структура проєкту

* `yolo/` — модулі підготовки даних, попередньої обробки зображень, навчання та оцінювання моделі YOLO;
* `curvature_data/` — модулі аналізу кривизни контурів та відновлення геометричних фігур;
* `results/` — результати проведених експериментів;
* `metrics.csv` — таблиця отриманих метрик якості.

## Запуск

Встановлення необхідних залежностей:

```bash
pip install -r requirements.txt
```

Запуск повного циклу експериментів:

```bash
python run_all_experiments.py
```

## Результат

Розроблена програмна система дозволяє автоматизувати процес формування наборів даних, застосування методів попередньої обробки зображень, навчання моделі YOLOv8 та оцінювання якості детекції геометричних об'єктів.

У результаті проведених експериментів виконано порівняння різних методів попередньої обробки зображень за метриками Precision, Recall, mAP50, mAP50-95 та F1-Score, а також досліджено можливість використання аналізу кривизни контурів для покращення представлення геометричних фігур у задачах комп'ютерного зору.
