## Опис проєкту

Проєкт реалізує чисельний аналіз математичної моделі «ліс–населення–тиск–зусилля» (Lata & Misra, 2017) та задачі оптимального керування збереженням лісових ресурсів.

Модель описує взаємодію чотирьох змінних: щільності лісових ресурсів B(t), чисельності населення N(t), рівня антропогенного тиску P(t) та обсягу відновлювальних зусиль E(t). Керуюча функція u(t) ∈ [0,1] моделює рівень законодавчих обмежень на використання ресурсів.

Головна мета — знайти оптимальну стратегію керування u*(t), що максимізує цільовий функціонал J(u) = ∫₀ᵀ (ω₁B − ω₂u²) dt, тобто балансує між вигодою від збереження лісу та витратами на регулювання.

## Основні завдання

- дослідження якісних властивостей моделі (додатність та обмеженість розв'язків);
- знаходження та аналіз стійкості точок рівноваги системи;
- доведення глобальної асимптотичної стійкості методом функцій Ляпунова;
- застосування принципу максимуму Понтрягіна для знаходження оптимального керування;
- чисельна реалізація алгоритму Forward-Backward Sweep;
- порівняльний аналіз різних стратегій керування.

## Запуск

### Порівняльний аналіз сценаріїв керування

```bash
python simple_solve.py
```

Будує графіки динаміки лісових ресурсів B(t) при u=0, u=0.5 та u=1.0 і виводить значення функціоналу J для кожного сценарію.

### Оптимізація кусково-сталого керування

```bash
python forward-backward.py
```

Знаходить оптимальне кусково-стале керування на m сегментах та будує графіки динаміки B(t) і керування u*(t).
