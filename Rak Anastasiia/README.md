# Моделювання процесу реакції-дифузії методом скінченних елементів (2D)

Розв'язання двовимірного нестаціонарного рівняння реакції-дифузії
методом скінченних елементів (МСЕ) із застосуванням схеми
Кранка–Ніколсона для інтегрування за часом.

## Посилання на репозиторій

Вихідний код: https://github.com/nastiia-r/thesis

## Опис

Програма чисельно розв'язує крайову задачу для рівняння реакції-дифузії
на одиничному квадраті `[0, 1] × [0, 1]`:

```
∂u/∂t = ∇·(k ∇u) − β u + f
```

де:
- `u(x, y, t)` — шукана функція (наприклад, концентрація);
- `k(x, y)` — коефіцієнт дифузії;
- `β(x, y)` — коефіцієнт реакції;
- `f(x, y)` — функція зовнішнього джерела.

Дискретизація за простором виконується методом скінченних елементів
на рівномірній чотирикутній сітці (елементи типу `D2QU4N`), а за часом —
неявною схемою Кранка–Ніколсона (`θ = 0.5`).

Підтримуються граничні умови Діріхле та Неймана.

### Структура проєкту

| Файл | Призначення |
|------|-------------|
| `main.py` | Демонстраційний запуск: перший тест (`Exp1_Active_Source`), апроксимація 1 |
| `test.py` | Повний набір із трьох тестових сценаріїв (апроксимація 2) |
| `mesh_2d.py` | Побудова скінченно-елементної сітки |
| `base_functions_2d.py` | Базисні функції елемента (для `ap = 1` та `ap = 2`) |
| `system_2d.py` | Формування локальних і глобальних матриць (жорсткості, мас, реакції) та вектора навантаження |
| `finite_element_2d.py` | Застосування граничних умов (Діріхле / Нейман) |
| `graph2d.py` | Візуалізація: анімація (`.gif`) та статичні зрізи (`.png`) |
| `verification_run.py` | Верифікація за збіжністю по сітці / апроксимації |
| `verification_time_run.py` | Верифікація за збіжністю по кроку часу |

## Вимоги

- Python 3.10 або новіша версія
- Залежності перелічені у `requirements.txt`:
  - `numpy`, `scipy`, `sympy`, `matplotlib`, `pillow`

## Встановлення

1. Клонувати репозиторій:

   ```bash
   git clone https://github.com/nastiia-r/thesis.git
   cd thesis
   ```

2. Створити та активувати віртуальне середовище:

   ```bash
   python3 -m venv venv
   source venv/bin/activate        # Linux / macOS
   # venv\Scripts\activate         # Windows
   ```

3. Встановити залежності:

   ```bash
   pip install -r requirements.txt
   ```

## Запуск

Демонстраційний запуск (один тест, апроксимація 1):

```bash
python main.py
```

Повний набір тестів:

```bash
python test.py
```

> Компіляція не потрібна — Python є інтерпретованою мовою.
> Достатньо встановити залежності та запустити скрипт.

## Результат

Після запуску `main.py` у кореневій теці проєкту з'являться файли:

- `Exp1_Active_Source.gif` — анімація еволюції розв'язку в часі;
- `Exp1_Active_Source_t0_0.png` — розв'язок у момент `t = 0.0`;
- `Exp1_Active_Source_t1_0.png` — розв'язок у момент `t = 1.0`;
- `Exp1_Active_Source_t3_0.png` — розв'язок у момент `t = 3.0`.

## Параметри першого тесту (`Exp1_Active_Source`)

| Параметр | Значення |
|----------|----------|
| Область | `[0, 1] × [0, 1]` |
| Сітка | `20 × 20` елементів |
| Апроксимація | `ap = 1` (лінійні елементи) |
| Коефіцієнт дифузії `k` | `0.01` |
| Коефіцієнт реакції `β` | `0.02` |
| Початкова умова | `2.0 · exp(−30·((x−0.3)² + (y−0.5)²))` |
| Зовнішнє джерело `f` | `5.0 · exp(−50·((x−0.7)² + (y−0.5)²))` |
| Граничні умови | Діріхле `u = 0` на всіх межах |
| Кінцевий час `t_end` | `3.0` |
| Крок за часом `dt` | `0.05` |
