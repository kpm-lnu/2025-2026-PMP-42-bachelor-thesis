## Опис проєкту

Проєкт реалізує систему надійного відстеження об'єктів на основі комбінації класичних алгоритмів комп'ютерного зору — трекерів CSRT та KCF, фільтра Калмана з функцією Хьюбера для згладжування траєкторії та RANSAC-перевиявлення для відновлення об'єкта після оклюзії.

Основна мета проєкту — дослідити та порівняти сучасні підходи до відстеження об'єктів, оцінити їх стійкість в умовах оклюзії та зміни зовнішнього вигляду, а також реалізувати практичну систему відстеження об'єктів на відеозаписах з дрона.

## Основні завдання

Проєкт охоплює такі етапи:

- аналіз сучасних архітектур відстеження об'єктів (CSRT, KCF, фільтр Калмана);
- реалізація конвеєра виділення переднього плану (MOG2 + границі Canny);
- інтеграція RANSAC-перевиявлення на основі зіставлення ознак ORB;
- розробка дворежимної системи відстеження з інтерактивною корекцією користувача;
- оцінювання за допомогою порівняння траєкторій, абсолютної похибки у пікселях (Δx, Δy) та евклідової відстані;
- візуальний аналіз результатів відстеження та переходів між станами (TRACKING / OCCLUDED / REDETECTED / LOST);
- аналіз поведінки трекерів у складних сценах з частковою оклюзією.

## Запуск

### Режим 1 — звичайне відстеження

```bash
python Object_tracking.py --video drone_flight.mp4
```

1. Відкриється вікно з першим кадром — виділіть об'єкт мишею
2. Натисніть **SPACE** або **ENTER** для підтвердження
3. Відстеження запуститься автоматично
4. Натисніть **Q** для виходу
5. Після завершення збережеться графік траєкторії → `plots/mode1/trajectory.png`

### Режим 2 — паралельне відстеження CSRT + KCF з ручними корекціями

```bash
python Object_tracking.py --video drone_flight.mp4 --mode 2
```

1. Виділіть об'єкт мишею на першому кадрі → **SPACE/ENTER**
2. Кожні 10 кадрів відео зупиняється — відображаються bbox обох трекерів
3. Намалюйте вікно корекції (де об'єкт насправді знаходиться) → **SPACE/ENTER**
4. Натисніть **ESC** у вікні корекції для завершення
5. Після виходу зберігаються графіки → `plots/mode2/`

Графіки режиму 2:
| Файл | Зміст |
|---|---|
| `trajectory_csrt.png` | Траєкторія CSRT vs користувач |
| `trajectory_kcf.png` | Траєкторія KCF vs користувач |
| `errors_csrt.png` | Абсолютні похибки CSRT (Δx, Δy, Евклід) |
| `errors_kcf.png` | Абсолютні похибки KCF (Δx, Δy, Евклід) |
| `distance_csrt.png` | Евклідова відстань CSRT від позиції користувача |
| `distance_kcf.png` | Евклідова відстань KCF від позиції користувача |

### Використання веб-камери

```bash
python Object_tracking.py --camera 0
```

### Збереження відео з відстеженням

```bash
python Object_tracking.py --video drone_flight.mp4 --output result.mp4
```

## Основні параметри

| Параметр | За замовч. | Опис |
|---|---|---|
| `--tracker` | `CSRT` | Алгоритм трекера: `CSRT` або `KCF` (тільки режим 1) |
| `--mode` | `1` | Режим роботи: `1` — звичайний, `2` — з корекцією |
| `--max-occluded` | `60` | Кадрів до переходу зі стану OCCLUDED у LOST |
| `--huber-delta` | `15.0` | Поріг Huber-функції у фільтрі Калмана (px) |
| `--hist-threshold` | `0.52` | Поріг відстані гістограм Бхаттачаріі |
| `--iou-threshold` | `0.15` | Мінімальний IoU для підтвердження bbox |
| `--warmup-frames` | `30` | Кількість кадрів для прогріву фону MOG2 |
| `--output` | — | Шлях для збереження вихідного відео |

## Стани трекера

| Стан | Колір рамки | Опис |
|---|---|---|
| `TRACKING` | Зелений | Об'єкт знайдено та відстежується |
| `OCCLUDED` | Помаранчевий | Об'єкт тимчасово перекрито |
| `REDETECTED` | Жовтий | Об'єкт знайдено повторно після оклюзії |
| `LOST` | Червоний | Об'єкт втрачено |

## Приклади

```bash
#Режим 1 у звичайному його вигляді
python Object_tracking.py --video drone_flight.mp4 --mode 1
# Режим 1 з трекером KCF та збереженням відео
python Object_tracking.py --video drone_flight.mp4 --tracker KCF --output out.mp4

# Режим 2 з підвищеним порогом гістограми
python Object_tracking.py --video drone_flight.mp4 --mode 2 --hist-threshold 0.6

# Режим 1 з довшим вікном Kalman-фільтра
python Object_tracking.py --video drone_flight.mp4 --max-occluded 120 --median-window 9
```
