## Опис проєкту

Цей репозиторій містить програмне забезпечення та матеріали бакалаврської кваліфікаційної роботи, присвяченої дослідженню та чисельному розв'язуванню нестаціонарних одновимірних задач адвекції-дифузії з великими числами Пекле. 

При високих числах Пекле (Pe ≫ 1), коли в системі переважає конвективний перенос, класичний метод скінченних елементів (МСЕ) з барицентричними функціями форми призводить до появи нефізичних осциляцій (числової дисперсії) поблизу зон великих градієнтів розв'язку (шарів стоку). Для усунення цього ефекту в програмі реалізовано метод стабілізації **SUPG (Streamline Upwind/Petrov-Galerkin)** — метод Петрова-Гальоркіна з потоком уверх, який вводить штучну дифузію виключно вздовж ліній току, забезпечуючи стійкість та гладкість чисельного розв'язку без втрати точності.

### Основний функціонал програми:
1. **Чисельне моделювання:** Розв'язування одновимірного рівняння адвекції-дифузії за допомогою МСЕ з лінійними елементами.
2. **SUPG Стабілізація:** Можливість інтерактивного ввімкнення/вимкнення стабілізації для порівняння схем та демонстрації ефекту числових осциляцій.
3. **Автоматичний перерахунок параметрів:** Гнучкий зв'язок між фізичними та сітковими характеристиками. Користувач може обрати один із трьох режимів автоматичного обчислення:
   * Розрахунок локального числа Пекле (Pe) за заданими швидкості (u) та дифузії (D).
   * Визначення необхідного коефіцієнта дифузії (D) за цільовим значенням Pe.
   * Визначення швидкості потоку (u) за цільовим значенням Pe.
4. **Графічний інтерфейс (GUI):** Інтуїтивна панель керування на базі бібліотеки tkinter з інтегрованими інтерактивними графіками matplotlib для відображення динаміки профілю концентрації у часі та кінцевого стану системи.

## Вимоги до середовища та залежності

Для запуску застосунку необхідне встановлене середовище **Python 3.8+**.

Програма використовує такі сторонні бібліотеки:
* `numpy` — для матрично-векторних операцій та розв'язання систем лінійних алгебраїчних рівнянь (СЛАР).
* `matplotlib` — для побудови графіків та інтеграції їх у вікно програми.

Всі інші модулі (`tkinter`, `ttk`) є частиною standard library Python.
