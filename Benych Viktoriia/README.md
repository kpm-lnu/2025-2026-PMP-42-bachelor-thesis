# Чисельне розв'язування збурених стаціонарних одновимірних задач реакції--адвекції--дифузії

Бакалаврська кваліфікаційна робота, присвячена дослідженню чисельних методів розв'язування сингулярно збурених задач реакції--адвекції--дифузії та аналізу їх стійкості в умовах домінування адвективного переносу.

## Загальна характеристика роботи

У задачах реакції--адвекції--дифузії при малих значеннях параметра дифузії виникають прикордонні шари та великі градієнти розв'язку, що суттєво ускладнює побудову стійких чисельних схем. Стандартні методи дискретизації в таких режимах можуть породжувати нефізичні осциляції та втрачати точність.

У роботі досліджено математичну постановку сингулярно збуреної задачі, побудовано варіаційне формулювання та реалізовано кілька чисельних підходів для її розв'язування. Особливу увагу приділено аналізу впливу малого параметра $\varepsilon$ та локального числа Пекле на поведінку чисельного розв'язку.

## Реалізовані чисельні методи

У межах проєкту реалізовано та досліджено:

- стандартний метод скінченних елементів (FEM);
- стабілізовану SUPG-схему;
- fitted-апроксимацію на основі модифікованих базисних функцій.

Для кожного підходу виконано:
- формування локальних матриць;
- складання глобальної системи;
- накладання крайових умов;
- обчислення чисельного розв'язку;
- аналіз похибок та стійкості.

## Проведені чисельні експерименти

У роботі виконано серію обчислювальних експериментів для різних значень параметра $\varepsilon$ та різної кількості елементів сітки $N$.

Зокрема, проведено:
- порівняння точного і чисельного розв'язків;
- дослідження похибок у нормах $E_{\infty}$ та $E_2$;
- аналіз збіжності чисельних схем;
- дослідження впливу числа Пекле;
- аналіз появи нефізичних осциляцій;
- порівняння ефективності стабілізаційних підходів.

Результати експериментів підтверджують, що SUPG-схема забезпечує найбільш стабільну поведінку та найменші похибки в режимі домінування адвекції, тоді як стандартний метод скінченних елементів може втрачати стійкість при малих значеннях параметра дифузії.

## Структура проєкту

### Основні програми

- `fem_1d_standard.py` — реалізація стандартного методу скінченних елементів;
- `fem_1d_supg.py` — реалізація SUPG-стабілізації;
- `fem_1d_fitted.py` — реалізація fitted-апроксимації;
- `convergence_analysis.py` — аналіз збіжності чисельних схем;
- `error_heatmap.py` — побудова теплових карт похибок;
- `oscillation_comparison.py` — дослідження чисельних осциляцій;
- `peclet_analysis.py` — аналіз впливу числа Пекле.

### Папки з результатами

- `plots_supg/` — графіки, побудовані в ході чисельних експериментів;
- `plots/` — додаткові результати візуалізації.

## Використані технології

Проєкт реалізовано мовою Python із використанням бібліотек:
- NumPy — для роботи з матрицями та чисельних обчислень;
- Matplotlib — для побудови графіків і візуалізації результатів.

Реалізація виконана без використання готових пакетів скінченноелементного аналізу, що дозволило самостійно реалізувати всі основні етапи побудови чисельної схеми.
