# Бакалаврська кваліфікаційна робота

**Студент:** Козловський Костянтин Андрійович  
**Група:** ПМП-42  
**Спеціальність:** 113 — Прикладна математика  
**Науковий керівник:** к.ф.-м.н., доцент Кухарський Віталій Михайлович  
**Рік:** 2026

## Тема

Чисельне розв'язування одновимірних задач перенесення забруднень у ґрунтах

## Опис роботи

Реалізовано метод скінченних елементів (МСЕ) для розв'язування
одновимірної стаціонарної крайової задачі для рівняння
адвекції-дифузії-реакції з граничними умовами Діріхле.

Розглянуто чотири приклади:
- Приклад 1: адвекція-дифузія без джерела (Pe = 10)
- Приклад 2: повна модель з джерелом та розпадом (Pe = 5)
- Приклад 3: витік нафтопродуктів при великому числі Пекле (Pe = 30)
- Приклад 4: добриво в кореневій зоні (Pe = 0.5)

## Структура

- `source-code/diplome_code.py` — реалізація МСЕ, аналітичні розв'язки, візуалізація
